# Contributing

This guide covers every repository in the [awesome-humans](https://github.com/awesome-humans) organisation. [Want in or out?](https://awesome-humans.net/want-in-or-out/#want-in) is the single reference for contributing. It says which repository a change goes to, whether to start with an issue or a pull request, and which form or template to use, for each of these:

- Suggest a source
- Challenge or correct an opinion
- Propose a new opinion, or a house opinion
- Fix a template, a skill, or the site

To ask to stop being cited, see [Opt out](https://awesome-humans.net/want-in-or-out/#opt-out). To report a vulnerability, see the [security policy](SECURITY.md).
